# Support

Quotarelay is currently a public local-first MVP.

## Best Effort Support

Use public issues for documentation corrections, local setup problems, reproducible local CLI/MCP/control-plane bugs, and bounded context/cache/memory/index behavior that differs from docs.

Please include:

- operating system,
- commit hash or version,
- command used,
- minimal reproduction using non-sensitive sample data,
- relevant error output.

## Security Reports

Do not report vulnerabilities through public issues. Follow `SECURITY.md`.

## Not Currently Supported

- hosted deployment support,
- production multi-user operation,
- provider API key handling,
- provider routing,
- cloud sync,
- enterprise support SLAs,
- exact provider billing or tokenizer analysis.
